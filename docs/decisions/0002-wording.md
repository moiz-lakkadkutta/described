# 0002 — Wording

The app never says "AI"; it says **described**. It never says "enable/disable"; it says **on/off**. Copy is plain, short,
second person, present tense — the same rules as audio description itself. Attribution is a full sentence.
Enforced for `packages/shared-ui/src/**` by `pnpm lint:words` (blocklist in `scripts/lint-words.mjs`).
