# Feature requests (with priority)

From the friction logs ([index](friction/README.md)) and the device run of 2026-10-10. Critical blocks a feature an app like ours needs;
Important costs real time or quality; Nice-to-have is a documentation or polish fix.

| Priority | Platform | Request | Why |
|---|---|---|---|
| Critical | Fire TV (catalog) | A self-serve catalog tier for small Appstore apps (even a capped number of titles), or Vega's Content Launcher on Fire OS; publish the EMBER XSD without a partner login. | Catalog integration is "select partners only" and CDF is closed to new integrations, so a new app cannot appear in Fire TV search, "Alexa, play … on Described" or Continue watching, and Content Personalization depends on it. Our draft feed (`GET /catalog/fire-tv.xml`) cannot be validated. [log](friction/2026-10-01-fire-tv-catalog-integration-is-partner-only.md) |
| Important | Fire TV (React Native) | A React Native package or sample for MediaSession + Alexa transport that reports each request to JS instead of acting on ExoPlayer; in react-native-video, a session without a notification service. | We wrote a Kotlin module to get "Alexa, pause / fast forward / restart" into a JS-owned player, and its lifecycle bug (inactive on `onPause`) failed device check 14 (PR #31). [log](friction/2026-10-01-alexa-transport-needs-a-native-media-session.md) |
| Important | AWS (Transcribe / Bedrock Nova) | An AWS-native audio-event (sound classification) capability — e.g. Transcribe returning labelled non-speech events with timestamps, or Nova audio understanding — to feed `[sound]` cues in rich captions. | Transcribe gives speech only, no audio-event labels, so our rich-caption sound tags stay sparse (Nova Lite guesses them from text and invents non-sounds). Important, not Critical: captions and descriptions ship without it, but SDH quality for deaf and hard-of-hearing viewers is capped until it exists. [log](friction/2026-10-01-nova-lite-json-echoes-input.md) |
| Important | Fire TV (devices) | State each model's maximum decoder frame size (AFTSS: 1920×1088) on the device specifications page; have react-native-video report the selected decoder and any capability fallback. | 2.39:1 content scaled to 1080 lines is 2534 wide; the stick fell back to a software decoder at 5–6 fps with no error to catch. [log](friction/2026-10-01-fire-tv-stick-caps-h-264-decode-at-1920-wide-and-falls-back-to-software-silently.md) |
| Important | Fire TV (sample) | Update AmazonAppDev/react-native-multi-tv-app-sample: HLS on in the react-native-video config, key events not consumed in MainActivity (or say only space-navigation focus works), a react-tv-space-navigation version that works with React 19, a new-architecture key source, and the Metro setup for a library shared by Fire OS and Vega. | Five logs trace back to the sample's setup and its libraries; the React 19 crash shows only in release builds. [HLS](friction/2026-09-26-sample-hls-disabled.md) · [focus](friction/2026-09-26-dpad-pressable-focus-and-latency.md) · [React 19](friction/2026-10-06-react-tv-space-navigation-5-crashes-release-builds-on-react-19.md) · [keyevent](friction/2026-10-01-react-native-keyevent-needs-the-old-architecture.md) · [Metro](friction/2026-09-26-metro-exports-condition-order.md) |
| Important | AWS (Bedrock Nova) | Document that Nova video understanding can invent on-screen text when asked to read it unconditionally; give an OCR confidence or a "no text visible" signal. | Invented text is the worst error for audio description: blind viewers cannot check it. [log](friction/2026-10-01-nova-pro-hallucinated-on-screen-text.md) |
| Nice-to-have | AWS (account) | Say "your account is on the Free plan, which does not include Amazon Transcribe" in the error, and show "verification pending" in the plan-upgrade response and `get-account-plan-state`. | ~30 min lost on an error that reads like an IAM problem, then a 403 from Bedrock while Transcribe already worked. [Transcribe](friction/2026-10-01-transcribe-free-plan-subscription-required.md) · [Bedrock](friction/2026-10-01-bedrock-account-verification-after-upgrade.md) |
